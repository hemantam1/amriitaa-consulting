# Amriitaa Consulting — Hemant Agaarwal Advisory

One-page website for retail, wholesale distribution and field sales advisory.

## Edit settings
Open `index.html` and find the `CONFIG` block near the bottom:

- `whatsappNumber` — country code + number, digits only (e.g. `27821234567` for South Africa)
- `googleFormUrl` — Google Forms → Send → `<>` embed → copy the `src` URL
- `jotformUrl` — Jotform → Publish → copy the form link

## Host it
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Vercel:** import this repo; no build step needed.
